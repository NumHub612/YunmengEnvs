# yunmeng-envs Roadmap

*云梦环境项目路线图*

项目最初起于2020年，起初主要还是作为cfd理论学习笔记使用。后续随着代码开发内容增长和新技术路线涌现，项目走向也随之发生了转变。当下，开源的优秀cfd项目已经很多了，没有必要再去重复造轮子。当然，如果仅是学习的目的，自己动手实现一遍算法依然是有价值的，但要作为一个提供给社区的开源项目，要求就更高了。

我们需要有自己的定位和理念，新的项目具有什么价值和意义，从而值得我们投入时间和精力。
